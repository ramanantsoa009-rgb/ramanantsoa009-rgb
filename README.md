## En ce moment

Je renforce mon côté **DevOps** en construisant une chaîne de déploiement complète sur Kubernetes :

- **Intégration continue avec Tekton** : récupération du code, construction de l'image, mise à jour automatique de la configuration
- **Déploiement GitOps avec Argo CD** : le cluster se synchronise tout seul sur le dépôt Git
- **Secrets chiffrés avec Sealed Secrets** : la configuration est versionnée sans jamais exposer de mot de passe
